Create @atlas/db Drizzle client/schema/migrations: immutable dataset JSONB/hash; run scope/revision/evidence JSONB; order-line quantities/override reason; approval audit. Expose typed repository methods, transaction boundary and migrate/seed scripts. Dataset JSONB holds supplied source inputs without inventing 1C raw format. Seed an idempotently labeled synthetic 24-month six-SKU dataset validated with shared schema: stable, seasonal, growing, stockout, isolated spike and recurrent borderline candidate; one warehouse/two categories/two suppliers. Keep dates fixed, asOf after full history; total rows below limits and candidates<=24. First smoke may select only one SKU through a category with one item; no fake runtime outputs in seed.
Seed may reference a shared in-package fixture builder reused by B09. Return dataset ID from seed output, never credentials. Ensure source IDs and approval revision constraints survive reload.
